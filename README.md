# 🌍 Pratolani nel Mondo — Dove Siamo Nel Mondo?

Interactive diaspora map connecting 2,000+ Pratolani from Pratola Serra (Avellino, Campania) across every continent.

**Features:** Leaflet map · 30 pre-seeded historical pins · Self-service pin form · Surname autocomplete · CSV import · Bilingual IT/EN · Insights dashboard · 5,000 years of history

**Created by** Antonio Michael De Palma (Tony De Palma) — Founder of the Pratolani nel Mondo Facebook group since 2014.

## Stack
- React 18 + Vite
- Leaflet + CartoDB Dark tiles
- localStorage persistence
- Deployed on Vercel
